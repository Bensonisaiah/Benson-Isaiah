# My Portfolio

Personal portfolio website showcasing my skills, projects, experience, and contact information.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Bensonisaiah/Benson-Isaiah.git
```

Install dependencies:

```bash
npm install
# or
pnpm install
```

Start development:

```bash
npm run dev
# or
pnpm dev
```
